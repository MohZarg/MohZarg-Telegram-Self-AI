# Contributing

Contributions are welcome. The project is intended to remain free and open source, with no paid tier, mandatory subscription, license key, paywall, or feature gating.

## Before contributing

1. Check existing issues and discussions to avoid duplicate work.
2. Open an issue for substantial changes and describe the intended behavior.
3. Keep pull requests focused and document user-visible changes.
4. Never include credentials, Telegram sessions, private user data, or production logs.
5. Add or update tests for changed behavior.

## Quality expectations

- Prefer clear, typed, maintainable code.
- Validate configuration and fail with actionable error messages.
- Handle Telegram API errors, rate limits, retries, and shutdown safely.
- Keep logs useful while redacting secrets and personal data.
- Document setup steps and environment variables.
- Do not claim a feature works until it has been implemented and tested.

## Pull requests

Include the purpose, implementation summary, test commands and results, configuration changes, and any security or migration considerations.
